### Vendor Invoice Intelligence System

An end-to-end application for estimating expected freight costs and identifying invoices that may need additional manual review. Technologies: Python, SQL, scikit-learn, SQLite, Streamlit.

### Intelligent Task Prioritizer

A Java Swing desktop application using a custom array-backed Binary Min-Heap. Its score is calculated as (Days Remaining × 2) − Importance Weight. Insertion and highest-priority extraction are O(log N); root access is O(1).

Repository: https://github.com/Dhruva105/Intelligent-Task-Prioritizer

### BigInt C++ Library

A C++ library for arbitrary-precision integer arithmetic, including large-integer arithmetic, operator overloading, factorial, and Fibonacci calculations.

Repository: https://github.com/Dhruva105/BigInt-CPP-Library

### Heart Disease Prediction

An educational Streamlit classifier project using a saved scikit-learn K-Nearest Neighbors model. The app aligns one-hot encoded inputs to the model's expected columns and applies a saved StandardScaler. The repository includes `heart.csv` with 918 rows, 11 input columns, and a target. The upstream dataset source and model evaluation results are not documented. This project is not clinically validated and is not a medical diagnostic tool.

Technologies: Python, Streamlit, scikit-learn, Pandas, NumPy, Plotly, Joblib.  
Repository: https://github.com/Dhruva105/heart-disease-prediction
